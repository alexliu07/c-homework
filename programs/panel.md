> 出题助教：罗荣鑫
> 
> 验题助教：

​CSV​（Comma-Separated Values，逗号分隔值）是一种用于存储表格数据的纯文本文件格式，每一行代表一条记录，记录中的字段由逗号分隔。为了易读性考虑，在控制面板上，需要将 csv 格式的用户记录输出为表格的形式。

在本题中，给定一个参数和一条用户记录，你需要按参数要求的格式输出这一条用户记录，参考“输出格式”一节。

## 输入格式

输入共两行。

第一行一个整数 $W$，表示宽度参数。用法见“输出格式”一节。

第二行三个字符串，用逗号隔开。

## 输出格式

输出共三行，每行 $W+15$ 个字符，表示控制台的显示结果。格式如下：

（这是 $W = 7$ 的情况）

```
| ID       | 114455  |
| Username | abcdefg |
| Email    | a@b.c   |
```

ID、用户名和邮箱均左对齐输出，宽 $W$ 个字符，若过长则截断。

## 样例

### 样例 1

**输入**

``` text
9
1144,En Xi,my@e.mail
```

**输出**

``` text
| ID       | 1144      |
| Username | En Xi     |
| Email    | my@e.mail |
```

### 样例 2

**输入**

``` text
4
1144,En Xi,my@e.mail
```

**输出**

``` text
| ID       | 1144 |
| Username | En X |
| Email    | my@e |
```

## 提示

ID、用户名、邮箱均为非空字符串，长度均不超过 $50$，且均不包含 `,` 字符。

**用户名中可能含有空格。**
