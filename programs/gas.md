## 题目描述

> 出题助教：潘星宇
>
> 验题助教：宁锐 乔昕雨

Brian 最近学习了热力学，对气体状态方程十分感兴趣。理想气体的状态方程为：$PV = nRT$

其中：

* $P$ 为气体的压强，单位为帕斯卡 (Pa)；
* $V$ 为气体的体积，单位为立方米 (m³)；
* $n$ 为气体的物质的量，单位为摩尔 (mol)；
* $R$ 为理想气体常数，**本题中请使用 $ 8.314 J/(mol·K)$；**
* $T$ 为气体的温度，单位为开尔文 (K)。

一天 Brian 的好朋友 Stewie 问了他一道有关容器内气体的量的问题：**假设气体被密封在一个正方体容器内，容器的边长为 $L$（单位为米），体积$V$可以通过公式 $V=L^3$ 计算,** 在已知压强、正方体边长、温度时，气体的物质的量 $n$ 是多少？

Brian 希望你能帮他回答这个问题。

## 输入格式

输入三个数值，以空格分隔：

* 一个浮点数，表示气体的压强 $P$；
* 一个浮点数，表示正方体容器的边长 $L$；
* 一个浮点数，表示气体的温度 $T$ 。

**输入可能使用普通或科学记数法表示。**

## 输出格式

输出气体的物质的量 $n$ ，**保留 5 位有效数字**，以**科学记数法**形式输出。

## 样例

**输入**

``` text
2.5e+04 1.0e-06 132
```

**输出**

``` text
2.2780e-17
```

## 提示

提示 1：**科学记数法**表示的浮点数的读入方法与普通浮点数一致。
