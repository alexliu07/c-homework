## 题目描述

传统益智玩具魔方是一个可转动的六面体，对它的操作可以分为两类，一种是对面的转动(下图1)，一种是对中轴的转动(下图2)。

```plain
      +--------------------+
     /                    /|
    /                    / |
   /                    /  |
  /--------------------/   |
 /    -------->       /|   |
+--------------------+ |   |
|                    | |   |
|                    |||   |
|                    |||   |
|                    |||   |
|                    |||   +
|                    |V|  /
|                    | | /
|                    | |/
|                    | /
|                    |/
+--------------------+
         (1)

      +--------------------+
     /                    /|
    /--------------------/ |
   /    -------->       /| |
  /--------------------/ | |
 /                    /| | |
+--------------------+ ||| |
|                    | ||| |
|                    | ||| |
|                    | ||| |
|                    | |V| |
|                    | | | +
|                    | | |/
|                    | | /
|                    | |/
|                    | /
|                    |/
+--------------------+
         (2)
```

然而这两种操作实际上还可以进行进一步的分解。
对于中轴的旋转，实际上是四条棱边的轮转，而对于面的旋转，同样是四条棱边的轮转加上一个面上的旋转。

这道题要求同学们通过多个一维数组的轮转和二维数组的旋转简单模拟实现一下棱边的轮转和面的旋转。实际上，如果想要完全模拟一个魔方，可能需要考虑一下每个面的法向量和该面的二维数组的关系，这属于几何方面的问题。

## 输入格式

第一行为`<操作类型> <大小n>`, 操作类型可以是`rotate`或者`line-rotate`。`rotate`表示二维数组的旋转，`line-rotate`表示多个一位数组的轮转。

之后为 `6*n` 行，每行 `n` 个数字，表示六个面(`n <= 100`)。

之后，如果操作类型是`rotate`，则给出一个数`side`，(0-5)，表示需要进行顺时针旋转的二维数组标号。

如果操作类型是`line-rotate`，则为4行，每行两个数表示`<side> <line>`，即给出四个需要轮换的行。
