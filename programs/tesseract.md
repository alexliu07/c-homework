> 小🔥发现 8 只方方正正的史莱姆聚集在了一起，奇迹般地变成了超正方体史莱姆！难道这就是奇迹史莱姆的真身？

**超正方体**是四维空间内的“立方体”。超正方体之于立方体，就如同立方体之于正方形。标准正交四维坐标系中，单位超正方体的顶点坐标为 $(x,y,z,w)$，每维坐标均只能为 $0$ 或 $1$。记各个顶点的编号为：

$$
id=8x+4y+2z+w.
$$

例如，顶点 $(0,0,0,0)$ 的编号为 $0$，顶点 $(0,0,0,1)$ 的编号为 $1$，顶点 $(0,0,1,0)$ 的编号为 $2$……不难看出，顶点编号的范围为 $[0,~15]$。

超正方体的棱由**只有一个维度的坐标不同**的两个顶点构成，如顶点 $(0,0,0,0)$ 与 $(0,0,0,1)$ 构成了超正方体的一条棱。

现在**给出一个可能不完整的单位超正方体**，请计算：添加哪一个缺失顶点，可以使**新增的棱**数量最多？

“新增的”棱是指原本缺失，添加顶点后出现的棱。

如果有多个候选顶点，选择编号最小的；如果原超正方体完整，则输出 $−1$。

## 输入格式

一个长度恰好为 $16$ 的字符串 $s$，仅由字符 `0` 和 `1` 组成，第 $i+1$ 个字符表示编号为 $i$ 的顶点状态，`0` 表示缺失，`1` 表示正常。

## 输出格式

一个整数，表示新增棱数量最多时，应添加的顶点编号。

若所有顶点均正常，输出 `-1`。

## 提示

#### 数据分布

- $20\%$ 的测试数据中，原超正方体是完好的。
- $20\%$ 的测试数据中，原超正方体是空的。
- $20\%$ 的测试数据中，原超正方体恰缺少一个顶点。

#### 样例解释

缺失顶点的编号为 $2,4,7,12,14$。分别添加它们时，新增完整棱的数量如下：

| 添加顶点 | 新增棱 |
| :------: | :----: |
|   $2$   |  $4$  |
|   $4$   |  $3$  |
|   $7$   |  $4$  |
|   $12$   |  $2$  |
|   $14$   |  $3$  |

因此，问题的答案为 $2$。

#### 解题思路

本题数据量很小，因此你可以**直接二重循环遍历**所有顶点的两两组合，再判断每个组合是不是超正方体中**合法的棱**。

至于计数，你可以任选一种你认为容易理解的方式：

- 先计算出初始棱的数量，然后遍历**每个缺失顶点**，分别计算添加每个缺失顶点后新增棱的数量；
- 枚举**所有棱（无论初始是否存在）**，为 `欲使初始不存在的棱出现，需要添加的顶点` 累计贡献值（思考什么情况下添加一个顶点能够新增棱？）。

  > 贡献值即为添加该缺失顶点能够新增的棱的数量
