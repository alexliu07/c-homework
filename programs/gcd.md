## 题目描述

> 出题助教：李和煦
>
> 验题助教：钱品亦

给定两个正整数，输出它们的最大公约数 (Greatest Common Divisor, GCD)。

两个正整数的公约数是指能够同时整除这两个数的数，最大公约数是其中的最大者。

可参考[最大公约数 - OI Wiki](https://oi-wiki.org/math/number-theory/gcd/)。

## 输入格式

两个正整数 $ 1 \leq a, b \leq 2 \times 10^9. $

## 输出格式

一个整数，即 $ a, b $ 的最大公约数。

## 样例

### 样例 1

**输入**

``` text
14 70
```

**输出**

``` text
14
```

### 样例 2

**输入**

``` text
66 24
```

**输出**

``` text
6
```
