#### 题目背景

一天🐜🐜给 C 语言课程课代表小 $E$ 分配了一个任务——根据所有试卷的分数打上相应的等第。小 $E$ 作为 C 语言爱好者，决定来编写一段程序帮助自己完成这个任务。

---

#### 问题描述

卷面分值在 $ 0 $ 分到 $ 100 $ 分之间。🐜老师决定让得分在 $ 90 $ 到 $ 100 $ 的同学获得 $A$ 等第，得分在 $ 80 $ 到 $ 89 $ 的同学获得 $B$ 等第，得分在 $ 70 $ 到 $ 79 $ 的同学获得 $C$ 等第，得分在 $ 60 $ 到 $ 69 $ 的同学获得 $D$ 等第，其余同学获得 $F$ 等第。小 $E$ 需要编写一个 C 语言程序，读入分数并输出这名同学的等第。然而，有的同学的分数🐜老师在批改时可能不小心多写了几个数字，这时候你就需要**提醒**老师了。

## 输入格式

输入一个整数 $ m $，表示该同学的分数。$ 0 \le m \le 2000$。

## 输出格式

输出共一行，为该同学的等第。如果输入不符合卷面分数的规范，则输出 `Wrong score`。

## 样例

### 样例 1

**输入**

``` text
99
```

**输出**

``` text
A
```

### 样例 2

**输入**

``` text
59
```

**输出**

``` text
F
```

### 样例 3

**输入**

``` text
1399
```

**输出**

``` text
Wrong score
```
