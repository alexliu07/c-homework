## 题目描述

欢迎使用 CPL DotOJ！这道题请你先读一读帮助页，再完成第一次代码提交。

打开 [OJ 帮助页](https://public.oj.cpl.icu/help)，阅读提交代码、查看评测结果和自定测试的说明。找到 C 语言的参考程序，将它完整复制到本题的代码编辑器中，选择 C17 或 C23，点击「提交代码」。

参考程序的功能很简单：读入两个整数 $a$、$b$，输出它们的和。

提交后，打开提交详情，查看本次程序的评测结果。

你也可以先用「自定测试」输入两整数，观察程序输出，再正式提交。

## 输入格式

输入一行，包含两个整数 $a$、$b$，以空格分隔。保证 $-10^8 \leq a,b \leq 10^8$。

## 输出格式

输出一行，包含整数 $a+b$。不要输出「请输入」或「答案是」等提示文字。
