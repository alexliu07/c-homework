查看内存是程序调试器的重要功能之一。假设你正在实现一个简单的内存查看器，你需要把已获得的内存数据以标准形式输出。

## 输入格式

一行，两个整数，以空格分隔，均不会超出 unsigned int 范围。表示内存地址 `addr` 和从该地址处获取的 32 位数据 `data`。

## 输出格式

一行。格式为：`addr:  d a t a`，均采用十六进制输出（参考测试样例及样例解释）。

## 样例

### 样例 1

**输入**

``` text
2147483664 4022250974
```

**输出**

``` text
0x80000010:  ef be ad de
```

### 样例 2

**输入**

``` text
12 16
```

**输出**

``` text
0x0000000c:  00 00 00 10
```

## 提示

请自行查阅无符号整数和十六进制数的读入和输出方式。本题理应不会因为 unsigned 的性质导致错误。（当然，开成 long long 也没有问题。但只开 int 肯定不行。）

注意输出时各处的空格数量和字符串长度。不要贸然使用制表符'\t'。

### 样例解释

* 样例一：12 和 16 的十六进制表示分别为 0xc 和 0x10。对于 `addr` ，我们将其输出为带有 0x 前缀的 8 位十六进制数，不足的在高位用 0 补齐，即 0x0000000c；对于 `data` ，我们将其高位补齐至 8 位后，均分为 4 段，每段之间添加空格后输出（不带 0x 前缀），即 00 00 00 10。
* 样例二：2147483664 和 4022250974 的十六进制表示分别为 0x80000010 和 0xefbeadde，长度足够，不需要在高位补 0，直接输出为 0x80000010 和 ef be ad de。

> 你可能会疑惑：如何在第二个数的内部加上空格？
> 
> 提示：尝试先把原数据每两位分隔开。假设我们使用的是十进制，num % 10 即可表示 num 的个位，num / 10 % 10 即可表示 num 的倒数第二位。那么十六进制呢？
