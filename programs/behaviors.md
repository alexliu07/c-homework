## 输入格式

共两行，第一行是一个整数 $n$，表示这组题目的数量，第二行是 $n$ 个整数，表示这组题目的题号 $x_i$。

**测试数据**范围约定如下：

* 对于 $ 85\\%$ 的数据，保证 $n = 1,~x_i \le 17$
* 对于 $ 100\\%$ 的数据，保证 $n\le17, ~ x_i \le 17$

但是如果没有使用位运算，单项全对的话，其实可以拿到 $ 90 \\%$ 的分数，所以如果你拿到了 $85$ 分，并不代表你全部选对了。

## 输出格式

共一行，分别表示上述题目答案的**按位与**，**按位或**和**按位异或**的结果，使用 `int` 类型的十进制表示，用空格隔开。

