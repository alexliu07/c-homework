## 题目描述

> 出题助教：罗荣鑫
>
> 验题助教：刘存玺 乔昕雨

小 Z 是一位热爱探险的旅行家，他拥有一张特殊的地图，上面记录着许多有趣的地点。为了方便规划旅行计划，他需要知道如何用最短的路线到达这些地点。具体来说，就是计算地图上一个点关于另一个点的相对位置。

现在，请你编写一个程序，帮助小 Z 完成这个任务。给定起点 A 和终点 B 的坐标，你需要计算出：

1. B 相对 A 的**直线距离**。
2. B 相对 A 的**方位角**。方位角**以正北方向为 $ 0$ 度**，顺时针方向递增，范围为 $[0, 360)$。

注意：在本题坐标系中，**y 轴正方向代表正北方向**。

## 输入格式

输入包含两行，每行两个整数。

第一行是起点 A 的坐标 $(x_A, y_A)$，以空格分隔；
第二行是终点 B 的坐标 $(x_B, y_B)$，以空格分隔。

## 输出格式

输出一行，包含两个浮点数，分别表示 B 相对 A 的距离和方位角，均保留四位小数，用空格隔开。

## 样例

### 样例 1

**输入**

``` text
10 10
22 17
```

**输出**

``` text
13.8924 59.7436
```

### 样例 2

**输入**

``` text
18 9
4 17
```

**输出**

``` text
16.1245 299.7449
```

## 提示

保证点 A 与点 B 不重合，横纵坐标的绝对值均不超过 $ 10^8$。

> 计算方位角时，你可以将坐标系平移，使起点 A 位于原点 $(0, 0)$。
