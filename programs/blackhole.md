#### 背景

在遥远的 *亥喇鲁* 大陆上，魔王 $Ganondorf$ 每年都要抓走大陆上的蚂蚁，原因不得而知。但是 $Ganondorf$ 是仁慈并且热爱数学的魔王，它深知不能抓掉所有的蚂蚁，不然明年只能抓空气了。

#### 描述

$Ganondorf$ 发现，*亥喇鲁* 蚂蚁的数量 $N$ 一定是**各位不同的三位数**。例如，$ 352$ 是符合要求的，$ 112$ 是不符合要求的。

它还发现，将蚂蚁的数量 $N$ 的每一位进行重新排列，能得到一些新的数字。将这些新的数字中最大的数字，减去最小的数字，能够得到新的一个三位数 $N^{'}$ 。

$Ganondorf$ 对这个 $N^{'}$ 十分满意，并且将其作为今年蚂蚁的新数量。$N-N^{'}$ 如果**大于零**，这个数量的蚂蚁将被抓走；否则魔王会用仁慈魔法造出 $|N-N^{'}|$ 只蚂蚁放回大陆。

如此进行了若干年后，$Ganondorf$ 发现蚂蚁的数量竟然稳定在了 $ 495$ 只！魔王对此十分惊讶，并且发现对任意初始蚂蚁数量 $N$ 都有此规律。所以它找到了你，想知道蚂蚁一开始数量为 $N$ 时，它总共会**抓走**多少只蚂蚁。

#### 形式化描述

对于一个给定的正三位数 $N$，每次将其各位数字**重组**得到的 最大数 与 最小数 作差，得到新的正三位数 $N^{'}$。一直做下去，最终一定会得到 $ 495$ 。请求出这个过程中所有**大于** $ 0$ 的 $N-N^{'}$ 之和。

## 输入格式

一个正三位数 $N$ ，含义同题目描述。

## 输出格式

一个非负整数 $M$ ，代表过程中所有**大于**$ 0$的 $N-N^{'}$ 之和。

## 样例

### 样例 1

**输入**

``` text
352
```

**输出**

``` text
253
```

### 样例 2

**输入**

``` text
540
```

**输出**

``` text
45
```

## 提示

#### 提示

样例一解释：

对于 $N=352$。第一步得到最大数为 $ 532$，最小数为 $ 235$，作差得到新数 $ 297$。对于 $ 297$，得到 $ 972-279=693$；对于 $ 693$，得到 $ 963-369=594$；对于 $ 594$，得到 $ 954-459=495$。过程中要求的和为 $(352-297) + (693-594) + (594-495) = 253$。

样例二提示：

只要一步就可以得到 $ 495$。重组得到的最小的数可以是二位数。

#### 测试数据

对于 $ 20$% 的数据，一步以内就可以得到 $ 495$。所以你可以不依赖循环而得到这些分数。

对于 $ 100$% 的数据，需要若干步才能得到 $ 495$。
