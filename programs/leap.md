### 题目背景

🐜部落的酋长 *ant-hengxin* 某天突发奇想，决定在每年的 2 月 29 日举行祭天大典，于是任命 *小🐜* 担任负责祭祀事宜的祭司长，任期数年。 不幸的是，*小🐜* 并不知道 ***如何判断自己任期的第一年和最后一年*** 是不是闰年。这可把 *小🐜* 急得像热锅上的🐜团团转，于是 *小🐜* 向你求助。

### 题目描述

看到急得团团转的小蚂蚁，你动用聪明的小脑瓜快速想了想，很快就回忆起了闰年和平年的判断方法：

1. 若公元年份 ***非 4 的倍数***（如 2001 年，1919 年），为平年。
2. 若公元年份 ***为 4 的倍数但非 100 的倍数*** （如 2004 年，2008 年），为闰年。
3. 若公元年份 ***为 100 的倍数但非 400 的倍数***（如1700 年，1800 年，1900 年），为平年。
4. 若公元年份 ***为 400 的倍数***（如 1600 年，2000 年，2400 年），为闰年。

## 输入格式

输入一行两个正整数 $n$ , $k$ 。其中 $n$ 表示 *ant-hengxin* 任命 *小🐜* 为祭司长的年份，任期 $k$ 年。

其中，$ 1 \le n \le 2^{63} - 1$, $ 1 \le k \le 2^{63} - 1$

## 输出格式

输出两行字符串，第一行表示 *小🐜* 任期的第一年是否为闰年，第二行表示 *小🐜* 任期的最后一年是否为闰年。

闰年则输出 `Leap year!`，平年则输出 `Normal year!`。

## 样例

### 样例 1

**输入**

``` text
2077 114514
```

**输出**

``` text
Normal year!
Normal year!
```

### 样例 2

**输入**

``` text
1919 2077
```

**输出**

``` text
Normal year!
Leap year!
```
