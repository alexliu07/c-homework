## 题目描述

读入两个整数 a, b, 请输出它们的和

## 输入格式

一行两个整数，以空格隔开

## 输出格式

一行一个整数，**禁止输出任何其他提示语**

## 样例

**输入**

``` text
100 1
```

**输出**

``` text
101
```
