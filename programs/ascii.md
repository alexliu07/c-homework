## 题目描述

> 出题助教：熊丘桓
>
> 验题助教：肖江 毛子钰

输入一个整数 $n$，输出该整数及其在 ASCII 表中对应的字符。

## 输入格式

输入一行，一个整数 $n$，其中 $ 65 \le n \le 90$。

## 输出格式

输出一行，一个整数 $n$ 和一个字符 $c$，其中 $c$ 的 ASCII 码是 $n$。

## 样例

**输入**

``` text
65
```

**输出**

``` text
65 A
```
