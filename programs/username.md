## 题目描述

> 出题助教：罗荣鑫
>
> 验题助教：刘存玺

用户名是彰显用户个性的重要方式，一个好的用户名可以让人印象深刻，拉近用户与平台之间的距离。然而，为了系统的稳定性，平台通常会对用户名设置一些合理的限制，例如用户名长度不能过长、过短、包含特殊字符等。

在本题中，你需要模拟处理“用户名过长”这种情况。你会读取一个用户名（字符串），并分别完成以下操作：

1. 计算用户名的总长度并输出；
2. 截断用户名超出 20 个字符的部分，并输出保留的部分。

## 输入格式

输入包含一行，仅有一个**可能含有空格的**字符串，即为给定的用户名。

## 输出格式

输出两行：

第一行一个整数，表示用户名的长度；

第二行一个**双引号包裹的**字符串，表示截断后的用户名。

## 样例

### 样例 1

**输入**

``` text
~[Z(e)ro is not null]~
```

**输出**

``` text
22
"~[Z(e)ro is not null"
```

### 样例 2

**输入**

``` text
 4E10x :D 
```

**输出**

``` text
10
" 4E10x :D "
```

### 样例 3

**输入**

``` text
abcdefghijklmnopqrstuvwxyz
```

**输出**

``` text
26
"abcdefghijklmnopqrst"
```

输入的字符串非空，且长度不超过 $100$。
