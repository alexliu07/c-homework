## 题目描述

> 出题助教：柳永昊
>
> 验题助教：李薛成 刘治元

请编写一个程序，输入一个整数（范围为 `int`），输出该整数的英文单词（全小写）表示。

#### 要求

1. 数字的英文表示应为标准的英文格式。
2. 输入 $ 0$ 时，直接输出`zero`（不要考虑 $-0$)。

## 输入格式

一个 `int` 类型的整数，范围为 $ [0, 999]$。

## 输出格式

输出该整数的英文单词表示，符合标准英文书写格式。

## 样例

### 样例 1

**输入**

``` text
1
```

**输出**

``` text
one
```

### 样例 2

**输入**

``` text
23
```

**输出**

``` text
twenty-three
```

### 样例 3

**输入**

``` text
123
```

**输出**

``` text
one hundred and twenty-three
```

## 提示

### 注意

1. `and` 的使用：如果一个数超过 $ 100$，且有十位或个位数，则需要在百位数与剩余的部分之间使用 `and`。
2. `-` 的使用：如果一个数超过 $ 20$，且有个位数，则需要在十位和个位之间使用 `-`。

### 数据范围

我们对输入数据做出以下保证：

* 有 $ 62$% 的数据：输入范围为 $ [0, 100]$ 且不涉及 `and` 以及 `-`。
* 有 $ 17$% 的数据：输入范围为 $ [ 0, 100]$ 且涉及 `and` 以及 `-`。
* 对于剩余 $ 21$% 的数据：输入范围为 $ [100, 999]$ 且涉及所有合法输入。

> 数字转换Ⅱ (converter-2.c) 会在未来与大家见面，预告一下数据范围会扩展到整个 `int` 范围，你可以提前想一下该怎么写 `thousand`/`million`/`billion` 了

### 提示

1. 推荐使用~~软院班级没教的~~ `switch case` 来大大简化条件判断，如果不会的话请翻书自学。指路教材 $P66$ 的 $ 5.3$ 章节。
2. 如果你想用超纲知识来简化更多的代码量，可以提前阅读教材 $P235$ 的 $ 13.7$ 字符串数组章节，在此贴一段代码，自行领会，不多赘述（毕竟超纲了，想看懂的话可以去翻翻书大概看看，这种方法就不需要 `switch` 了）：

```c
static char *ones[] = {
  "zero", "one", "two", "three", "four", "five", "six", "seven", "eight", "nine",
  "ten", "eleven", "twelve", "thirteen", "fourteen",
  "fifteen", "sixteen", "seventeen", "eighteen", "nineteen"};

static char *tens[] = {
  "0", "1", "twenty", "thirty", "forty", 
  "fifty", "sixty", "seventy", "eighty", "ninety"};

// 如何打印 123 的英文呢？像这样就行啦！
printf("%s hundred and %s-%s", ones[1], tens[2], ones[3]);
```
