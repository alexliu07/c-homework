## 题目描述

> 出题助教：熊丘桓（EagleBear2002）
>
> 这是一道算法题，朴素的想法是拿不到满分滴~
>
> 但其实也是一道模板题，请看知识点：[筛法 - OI Wiki (oi-wiki.org)](https://oi-wiki.org/math/number-theory/sieve/)

输入 $n$，输出 $[1,n]$ 闭区间的素数个数。

## 输入格式

一行一个整数$n$。

对于 $ 30\\%$ 的数据，保证 $n \le 1000$；

对于 $ 60\\%$ 的数据，保证 $n \le 10000$；

对于 $ 90\\% $的数据，保证 $n \le 1000000$；

对于 $ 100\\%$ 的数据，保证 $n \le 50000000$。

## 输出格式

一行一个整数 $m$，表示所求素数个数。

## 样例

### 样例 1

**输入**

``` text
2
```

**输出**

``` text
1
```

### 样例 2

**输入**

``` text
17
```

**输出**

``` text
7
```
