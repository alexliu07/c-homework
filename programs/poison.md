# 女巫的魔药 (poison.c)

- **竞赛**：exam-1
- **题目 ID**：417
- **时间限制**：1000 ms ｜ **内存限制**：256000 KiB
- **原题链接**：[https://public.oj.cpl.icu/contest/21/problem/417](https://public.oj.cpl.icu/contest/21/problem/417)

## 题目描述

> 出题助教：周静萱
>
> 验题助教：郭佳荣、郑袭明、曹宇航、赵心泉

你是一名新手女巫，为了延续女巫的荣耀，你当然要好好学习怎么做出完美的魔药。于是，怀揣着成为世界第一女巫的梦想，你虔诚地打开了《咕噜咕噜的奇迹！完美魔药的一二三四步……》。作为新手女巫宝典，该书记载了 $n$ 条配方，每条配方形如：

```text
A + B = C
```

其中 `A`、`B`、`C` 都是整数编号。该配方表示**一份**魔药 `A` 与**一份**魔药 `B` 可以反应，生成**一份**魔药 `C`。配方不区分两种原料的顺序：`A + B = C` 也可以用于 `B` 与 `A`。任意一对原料至多对应一种产物。

坩埚最初为空，容量无限。魔药在其中逐层堆叠，每层恰好是一份魔药。你将按输入顺序执行 $q$ 次操作：

- `ADD s`：向最上层投入一份编号为 `s` 的魔药。**投入时不发生反应**。
- `BOIL`：熬煮一次，按下面的规则完成**一轮**反应。

每次熬煮只进行一轮反应。以本轮开始时的各层魔药及其相邻关系为准，从最下层到最上层依次处理：

1. 若当前层已参与本轮反应，则跳过。
2. 若其相邻的上层存在、尚未参与本轮反应，且两者有对应配方，则将这两层合成为一层产物，否则，当前层保持不变。
3. 反应不改变其他层的相对上下顺序。新产物及反应后新形成的相邻关系，只能在下一次熬煮时参与反应。

一次 `BOIL` 不会自动重复熬煮到稳定。只有遇到下一条 `BOIL`，才能开始下一轮反应。

投入的魔药不一定出现在配方中，没有对应配方的相邻魔药不会反应。同名原料的配方也需要两份魔药，单独一份不能反应，空坩埚或只有一层魔药时，`BOIL` 不改变状态。

请输出全部操作结束后，坩埚中从下到上的魔药名称。

## 输入格式

第一行包含三个整数 $m,n,q$，依次表示魔药种数、配方数和操作数。

接下来 $m$ 行，每行一个魔药名称，所有名称互不相同。按输入顺序从 $1$ 到 $m$ 编号。

接下来 $n$ 行，每行一条配方，格式为 `a + b = c`。其中三个小写字母分别代表输入中的三个整数编号，编号与符号之间用一个空格分隔。

接下来 $q$ 行，每行以一个大写操作关键字开头。`ADD s` 表示投入编号为 $s$ 的魔药，`BOIL` 表示熬煮一轮。配方和操作中的所有编号都在 $1$ 到 $m$ 之间。

## 输出格式

若坩埚非空，按**从下到上**的顺序，每行输出一层魔药的名称。同名魔药若占据多层，必须重复输出，不能去重。

若坩埚为空，输出一行 `EMPTY`。

## 提示

> 小 🔥 把他培育出的奇迹史莱姆送给了你，用来炼制魔药……

#### 数据范围

设 $m$ 为魔药种数，$n$ 为配方数，$q$ 为操作数。对于全部测试点，保证：

- $1 \le m \le 2000$，$1 \le n \le \min\left(200000,\frac{m(m+1)}{2}\right)$，$1 \le q \le 500000$。
- 设第 $i$ 次执行 `BOIL` 前坩埚中有 $k_i$ 层。保证所有熬煮开始时的层数之和 $\sum_i k_i \le 25000000$。
- 魔药按名称的输入顺序从 $1$ 到 $m$ 编号。名称互不相同，每行一个，长度为 $1$ 至 $20$，仅含大小写英文字母，区分大小写。
- 配方允许同名原料。交换原料顺序视为同一对，每对原料至多对应一种产物。所有操作合法。

| 分值  | 额外保证                                       |
| ----- | ---------------------------------------------- |
| 20 分 | 至少有一次`ADD`，所有熬煮均不发生反应。        |
| 10 分 | 所有操作均为`BOIL`，输出 `EMPTY`。             |
| 30 分 | $n \le 50$， $q \le 10000$，至少发生一次反应。 |
| 20 分 | $n \le 50$， $q$ 无限制，至少发生一次反应。    |
| 20 分 | $q \le 10000$，$n$ 无限制，至少发生一次反应。  |

#### 解题提示

**60 分解法**

你最直接的想法，暴力遍历即可。

**80 分解法**

暴力遍历查找配方会花费大量时间，我们需要一个更好的方式从两种原料找到它们的产物。

思考：存在配方时，每两种原料都可以对应唯一的产物；相似地，在平面直角坐标系里，每一组 x，y 都有唯一对应的点……会不会有什么联系呢？

**100 分解法 1**

- 压缩数组
  如果反应时只是在数组中擦掉被反应的两药之一，那我们之后每次遍历锅中的药时，都还要再次扫过它。能不能把这些空位填起来呢？
  想象一下：我们把所有反应产生或没有变化的药品装进了一个新坩埚中，从而避免产生空位。由于任何反应都是让药品总量减少的，我们可以直接在原数组上进行操作。
  你可以用两个下标 $idx1$ 和 $idx2$ 分别表示当前遍历到的药品位置和当前“新坩埚”的药品总量。如果不反应，直接原样粘贴，$idx1$ 和 $idx2$ 都前进一层；如果反应，那 $idx1$ 前进两层，$idx2$ 只前进一层。

**100 分解法 2**

- 链表
  写一个链表或者类似链表的东西也可以通过本题。由于链表不属于本次考试范围，这里不再详述。

#### 样例解释

**样例一**

依次执行 `ADD 4`、`ADD 2`、`ADD 1` 后，4 号魔药在底层，2 号在中层，1 号在顶层。执行 `BOIL` 时从底层开始。依据配方 `2 + 4 = 5` ，底部两层先合成 5 号魔药。2 号已参与反应，不能再与 1 号反应。5 号是本轮的新产物，配方 `1 + 5 = 6` 要到下一次熬煮才有机会使用。

从下向上先读到 5 号，再读到 1 号，输出如下。

```text
PhoenixTear
Moonwater
```

**样例二**

Stardust
Moonwater
DragonBlood

**样例三**

投料后，从下向上的编号依次为 1、3、1。配方 `1 + 1 = 2` 需要两份相邻的 1 号魔药，但它们被 3 号魔药隔开，本次熬煮没有发生反应。底层和顶层各有一份 Rose，两份都要输出。

```text
Rose
CrystalBarrier
Rose
```

**样例四**

坩埚最初为空。唯一的操作是 `BOIL`，没有投入任何魔药，因此输出一行 `EMPTY`。
