## 题目描述

> 出题助教：毛子钰

“阿伟，你又在玩电动喔，休息一下吧，去看个书好不好？”。烦人的阿嫲又在念叨，阿伟怕阿嫲叫杰哥来教训自己，于是开始写 OJ，做完《[阶乘的和 Ⅰ]》这一题（~~倒反天罡，这道题会出现在未来发布的计分作业里~~），阿伟觉得出题人太逊了，于是改了一下题目：

给定正整数 $n$，计算 $\left(\sum\limits_{i=1}^ni!\right)\ \text{mod}\ 1000000007$ 的值，其中 $i!$ 为 $i$ 的阶乘，$\text{mod}$ 表示取模。

## 输入格式

一个正整数 $n$，$ 1\leqslant n\leqslant 2\times 10^8$

## 输出格式

一个整数，为 $ \left(\sum\limits_{i=1}^ni!\right)\ \text{mod}\ 1000000007$ 的值

## 样例

### 样例 1

**输入**

``` text
3
```

**输出**

``` text
9
```

### 样例 2

**输入**

``` text
13
```

**输出**

``` text
749977071
```

**如果不考虑取模运算**，计算阶乘可以很容易地实现为：

```cpp
long long res = 1LL;
for (int i = 1; i <= m; i++)     // 计算 m 的阶乘
    res *= i;
```

那么计算本题答案的代码可以写成

```cpp
long long ans = 0LL;
for (int i = 1; i <= n; i++)
{
    long long f_i = 1LL;
    for (int j = 1; j <= i; j++)    // 计算 i 的阶乘
        f_i *= j;
    ans += f_i;
}
```

如何取模？例如我们要计算 $(1+2+\cdots+n)$ % $m$，可以

```cpp
long long mod_res = 0LL;
for (int i = 1; i <= n; i++)
    res = (res + i) % m;
```

**为什么可以这么写？如何推广到乘法？**

但是提交这份代码会得到 “时间超限”。

这是因为在计算 $i!$ 时，需要计算 $(i-1)!$，但是由于在 for 循环中，$(i-1)!$ 已经被计算过了。重复计算将导致代码时间复杂度呈指数及增长。

我们可以用空间来换时间，可以使用数组 ```f``` 来保存计算结果，即 ```f[i] = i!```

这时候阶乘函数可以写为

```cpp
long long f[maxn] = { 0 };
// You need to define maxn
f[0] = 1LL;
for (int i = 1; i <= n; i++)
    f[i] = i * f[i - 1];
```

用这份代码加上**取模**可以得到 90 分，原因是内存超限。思考一下：for 循环每次计算得到的结果之间有什么关系？在计算完 ```f[i]``` 后，```f[i - 1]``` 就没有用了，可以不使用数组吗？

**注意数据范围，你可能需要使用 long long**
