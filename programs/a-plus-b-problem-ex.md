## 题目描述

> 出题助教：毛子钰

湳涼汏学第五食堂香積八方的仙贝甜琐耗儿发现：

在大部分机器上

* int 为 32 位，能表示的范围是 $-2^{31}\sim 2^{31}-1$
* long long 为 64 位，能表示的范围是 $-2^{63}\sim 2^{63}-1$
* double 比 long long 大，但是肯定表示不了像 $ 114514^{1919810}$ 这么大的数

有一天仙贝突发奇想，该如何用 C 语言计算 $ 1145^{14}+19198^{10} $？

观察到 $ 1145^{14} = 6656973275315950491103044695023687744140625,\ 19198^{10}=6800797967675697630363274958942030954497024$，不管是 long long 还是 double 都表示不了，仙贝想不出来，用一罐红茶作为报酬，请求聪明的你帮忙。

## 输入格式

输入包含多行，输入两个整数 $a,\ b$

$ 0\leqslant a,\ b\leqslant 10^{1000}$

## 输出格式

输出多行，每行一个整数，为相应行的 $a+b$ 的值

## 样例

**输入**

``` text
114514 1919810
6656973275315950491103044695023687744140625 6800797967675697630363274958942030954497024
```

**输出**

``` text
2034324
13457771242991648121466319653965718698637649
```
