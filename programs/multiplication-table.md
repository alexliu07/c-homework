## 题目描述

> 出题助教：顾龙
>
> 验题助教：钱品亦

输入一个正整数$N (1 <= N <= 9)$，请编写程序输出对应的九九乘法表。

## 输入格式

一个正整数$N (1 <= N <= 9)$。

## 输出格式

按照以下格式输出 $N$ 级的九九乘法表：

- 每一行的运算从$ 1 \times k$到 $k \times k$，其中 $k$ 为当前行数$（1 ≤ k ≤ N）$。
- 每个表达式格式为 axb=结果，之间用空格隔开。
- 使用 x 表示乘号。

## 样例

### 样例 1

**输入**

``` text
1
```

**输出**

``` text
1x1=1
```

### 样例 2

**输入**

``` text
2
```

**输出**

``` text
1x1=1
1x2=2 2x2=4
```
