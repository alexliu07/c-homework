## 题目描述

本题提供 **6 个独立错误版本**。请切换修复任务，只修改各自标出的可编辑区域。版本 01–06 依次为 **30、20、20、10、10、10 分**，合计 $100$ 分。每个版本通过它的全部测试即可获得对应分数；可以分次提交，其他版本未修好不影响已通过版本得分。

> 出题助教：肖江
>
> 验题助教：熊丘桓 毛子钰

编写一个程序，要求用户输入一个软妹币数额，然后显示出如何用最少张数的 $50$ 软妹币，$20$ 软妹币、$10$ 软妹币、$5$ 软妹币和 $1$ 软妹币钞票来付款。

## 输入格式

一个整数 $n$，$0 \leq n \leq 10000$，表示输入的软妹币数额。

## 输出格式

共五行，每行一个整数，分别表示所需要的 $50$ 软妹币，$20$ 软妹币、$10$ 软妹币、$5$ 软妹币和 $1$ 软妹币钞票的数量。

## 提示

提示: 这本是一道算法题。不过，你最朴素的那个想法（先使用大额钞票，再使用小额钞票）恰好就是正确的。 有兴趣的话可以证明一下。
