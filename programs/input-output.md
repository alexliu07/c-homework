## 题目描述

请自己写一个 C 语言程序，让它读入一个整数，再按指定的格式输出这个数，做一个“复读机”。

可以先在本地 IDE 中编写和运行，再把完整的 C 源代码提交到 OJ。题目注解中有输入、输出的用法提示。

## 输入格式

输入一个整数 $n$，满足 $0 \le n \le 1000$。

每次运行只需读入这一个数。

## 输出格式

输出一行，格式为：

```text
You entered: n
```

把其中的 `n` 替换成你读入的整数。注意 `You` 的首字母大写，使用英文冒号，冒号后有一个空格，行末换行。

只输出这一行，不要额外输出“请输入”等提示语。

## 提示

### 开始写程序

可以从这个框架开始。`int n = 0;` 声明一个整数变量，并把它的初始值设为 `0`。

```c
#include <stdio.h>

int main(void) {
    int n = 0;

    /* 在这里读入 n，再按要求输出。 */

    return 0;
}
```

### 读入和输出

用 `scanf` 读入整数时，`%d` 表示按整数读取，变量名前要加 `&`：

```c
scanf("%d", &n);
```

运行到这里，程序会等待输入。在运行窗口或终端里输入一个整数，再按回车即可。

用 `printf` 输出时，`%d` 会替换成变量的值，`\n` 表示换行，变量名前不加 `&`。例如：

```c
printf("Number: %d\n", n);
```

如果 `n` 的值为 `42`，这一句会输出 `Number: 42`。请把文字改成题目要求的 `You entered:`，与读入语句一起填到程序框架中。
