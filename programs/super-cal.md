## 题目描述

> 出题助教：李博颖

请实现一个只支持两个**整数**运算的简易计算器，支持操作加减乘除

[附加题选讲](https://njusecourse.feishu.cn/wiki/KOTzwWpYQijTWkkm6XycdG3anPe) 附参考实现 3 份，刷不出来的话强制刷新页面（Ctrl+Shift+R）。

## 输入格式

第一行输入数据组数 $T\ (T \le 100)$ ，接下来 $T$ 行每一行的格式为 $a \ \text{op} \ b$

| $\text{op}$ | $\qquad a, b$ 的范围                           |
| ----------- | ---------------------------------------------- |
| $+$         | $\qquad 0\leqslant a, b < 10^{10001}$          |
| $-$         | $\qquad 0\leqslant b \leqslant a < 10^{10001}$ |
| $*$         | $\qquad 0\leqslant a, b < 10^{101}$            |
| $/$         | $ \qquad0\leqslant a,b < 10^{101}$             |

---

其中，$ 25\\%$的数据保证只有加法

$ 50\\%$的数据保证只有加法和减法

$ 75\\%$的数据保证只有加法、减法和乘法

## 输出格式

每行输出对应一行输入表示答案

## 样例

**输入**

``` text
4
1 + 1
2 - 2
3 * 3
5 / 4
```

**输出**

``` text
2
0
9
1
```
