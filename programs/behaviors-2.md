## 题目描述

> 出题助教：灵感忘记来源于哪了（by：神必的出题人） 张哲恺在原题中加入了位运算
>
> 题目移植和补充：赵心泉
>
> 验题人：你

《老猴不算》又新推出了一种题目，计算起来相当耗时，为了打榜（请不要这样）你决定为它写一段程序。这次，题目会给出若干用题号标注的陈述，如果这句陈述的做法是正确的，这道题目的答案就是它**对应的题号**；否则答案是它**对应的题号的相反数**。最终《老猴不算》会给出一组题号，你需要输出这组题目所有答案的**按位与**，**按位或**和**按位异或**的结果。

炸鱼的你又一次成功爬取到了题库如下：

1. ant-hengxin 想为 a、b、c 都赋初值 1，他这么写：

   ```C
   int a, b, c = 1;
   ```
2. ant-hengxin 想要判断 n 的奇偶性，他这么写：

   ```C
   if (n & 1 == 0) { ... }
   ```
3. ant-hengxin 想要把数组全赋初值 1，他这么写：

   ```C

   ```
4. ant-hengxin 对数组一通操作后，想把它恢复为全为 0，他这么写：

   ```C
   int nums[10] = {0};
   // other codes
   nums = {0};
   ```
5. ant-hengxin 需要为长度为 $10^3$ 的字符串开数组，他这么写：

   ```C
   char str[1000];
   ```
6. ant-hengxin 需要开一个 $10^5$ 的 int 数组，他这么写：




## 输入格式

共两行，第一行是一个整数 $n$，表示这组题目的数量，第二行是 $n$ 个整数，表示这组题目的题号 $x_i$。

**测试数据**范围约定如下：

* 对于 $60\%$ 的数据，保证 $n = 1,x_i \leq 12$；
* 对于 $ 100\%$ 的数据，保证 $n \leq 12, x_i \leq 12$。

也就是说，如果你没有使用位运算，单项全对的话，可以拿到 $60\%$ 的分数。

## 输出格式

共一行，分别表示上述题目答案的**按位与**，**按位或**和**按位异或**的结果，使用 `int` 类型的十进制表示，用空格隔开。
