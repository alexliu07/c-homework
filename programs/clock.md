## 题目描述

> 出题助教：余明晖
>
> 验题助教：乔昕雨 张哲恺

小 $h$ 需要你帮助 Ta 将 $ 24$小时制的时间转换为$ 12$小时制，并附上当前所处时间段的标记上午(a.m.)下午(p.m.)，时间与时间段标记之间**以一个空格隔开**。

由于小 $h$ 具有强迫症，Ta 需要你保持小时与时间均是**两位整数**。

## 输入格式

$ 24$小时制的时间 $t$，小时与分钟之间以一个`:`隔开，即**小时:分钟**，且 ${00:00}\leq t\leq{23:59}$。

## 输出格式

转换之后的 $ 12$ 小时制时间，小时与分钟均为**两位整数**，并附带a.m.(上午)或p.m.(下午)，两者以**一个空格**隔开。

## 样例

### 样例 1

**输入**

``` text
9:31
```

**输出**

``` text
09:31 a.m.
```

### 样例 2

**输入**

``` text
14:51
```

**输出**

``` text
02:51 p.m.
```

## 提示

#### 本题转换规则

* 00:00 ~ 12:59只需加上时间标记：00:00 ~ 11:59为a.m., 其余为p.m.
* 13:00 ~ 23:59在时间标记的基础上需要减去12小时
